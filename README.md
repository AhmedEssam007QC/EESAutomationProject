Overview

This project is an automation testing framework developed to validate the functionality of the navigation bar within the EES system. It focuses on ensuring that all navigation elements behave as expected, providing a reliable and consistent user experience.

Purpose

The main goal of this project is to:

Automate test scenarios related to the navigation bar
Verify accessibility and correctness of navigation links
Ensure smooth transitions between different sections of the system
Detect UI or functional issues early in the development cycle
Scope

Currently, the project covers:

Navigation bar elements validation
Page redirection checks
Basic UI interaction scenarios

⚠️ This is an initial version of the project and serves as a foundation for future enhancements.

Tech Stack
Programming Language: Java
Automation Framework: Selenium WebDriver
Test Runner: TestNG / JUnit (update based on what you use)
Build Tool: Maven / Gradle (update if needed)
